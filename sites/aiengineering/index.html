Curriculum

Technical depth across the LLM stack.

Eight focus areas. Each ends with a working notebook or repo you can keep.

LLM API craft

Chat and completion APIs, system prompts, structured JSON output, tool calling, streaming and token budgeting.

Prompt systems

Few-shot patterns, chain-of-thought where it helps, guardrails, and failure modes when prompts drift.

Embeddings & chunking

Embedding models, chunk strategies, overlap, metadata filters and hybrid lexical + vector search.

RAG pipelines

Ingest → index → retrieve → rerank → generate with citations; hallucination checks before answers ship.

Vector databases

ChromaDB and comparable stores: collections, indexing choices, freshness and cost at modest scale.

Agents & MCP

Multi-step agents, MCP server design, tool allowlists and human checkpoints for risky actions.

Evaluation harnesses

DeepEval, Ragas and LangSmith-style suites: golden sets, regression gates and red-team probes.

Fine-tuning choices

When to fine-tune vs prompt vs RAG; dataset prep and LoRA / PEFT trade-offs.

Stack we practise

Tools you will touch on the builder track.

  • Python + TypeScript clients for major LLM APIs
  • ChromaDB (and comparable vector stores) for retrieval labs
  • MCP servers as the bridge between agents and real tools
  • DeepEval / Ragas-style metrics wired into a small CI gate
  • In-house apps (ResumeGenie, StudyMate, FeedbackPulse, MeetingMind) as reference implementations
