Do I need coding experience for the Playwright course?

No. The first chapters assume zero experience and build up JavaScript / TypeScript as you need it.

Your locator and Page Object thinking transfers directly; Playwright mostly removes the waiting and setup pain.

Any ordinary laptop that runs a modern browser and Node.js. No GPU required.
