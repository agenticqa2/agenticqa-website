Who we are

An AI and quality engineering company.

Agentic QA Technologies LLP (LLPIN ACV-7177, registered in Puducherry, India) works where AI systems meet software quality: building, testing and evaluating AI-powered software, and helping people and teams do the same.

AI-native quality engineering

Playwright and API automation with AI-assisted triage, CI/CD integration and test strategy for modern web products.

Custom AI agents

Task-specific agents connected to company data and tools through APIs and MCP servers, with human checkpoints where they matter.

LLM & agent evaluation

Evaluation suites (DeepEval, Ragas, LangSmith) that measure accuracy, safety and regressions in LLM and RAG features.

Automation consulting

Identify high-value automation opportunities, define API and MCP integration requirements, and create a delivery roadmap covering implementation, evaluation and CI/CD.

Skill programmes

Structured, hands-on programmes in AI engineering, Playwright + AI and NEET preparation, each run on its own site.

In-house tooling

Explore working AI applications built by our team, demonstrating RAG, structured LLM feedback, sentiment analysis and meeting summarisation.
