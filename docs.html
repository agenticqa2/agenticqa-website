Documentation

The full syllabus, in the open.

This is the actual course. Every chapter includes entry checks, a common-mistakes box, an exercise and a quiz.

Foundations

  1. Zero to automation testing — manual vs automated, setup from scratch
  2. AI for testers — prompting AI tools for test cases, test data and bug reports
  3. What is Playwright — browsers, locators, auto-waiting
  4. JS + TS essentials — only the ideas the framework uses
  5. BDD with Gherkin — Given/When/Then, tags, flow

Framework craft

  1. Page Object Model — the three rules, BasePage, fixtures
  2. Framework tour — every folder and file, end to end
  3. API testing in the framework — request contexts, REST checks, API-driven test data
  4. Handling hard cases — iframes, shadow DOM, sessions, Allure
  5. AI-assisted framework coding — generate, refactor and review page objects and tests with AI
  6. Solved capstone — empty folder to green suite

Professional edge

  1. Advanced concepts — sharding, traces, CI, debugging playbook
  2. Playwright MCP + AI agents — agent loop, healer, triage
  3. AI in CI/CD — AI failure analysis, self-healing locators, Jenkins and GitHub Actions
  4. Interview bank — Q&A, drill plan, scoring rubric
  5. Architect level — strategy, metrics, flaky-test policy
How our AI test agents are built

Three layers. One hard rule.

1

Intent (AI)

Requirements + RAG context → an LLM plans a structured test intent (JSON).

2

Validation

Schema checks, selector verification against the DOM and safety guards.

3

Execution

An MCP server + Playwright run the validated intent and capture evidence.

!

The rule

No LLM calls during execution — same intent, same actions, CI-safe results.
