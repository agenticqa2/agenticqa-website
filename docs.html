How our agents are built

Three layers. One hard rule.

1 · Intent layer (AI)

Natural-language requirements → RAG context → LLM plans a structured test intent (JSON). Claude, GPT, or local models.

2 · Validation layer (critic)

Schema checks, selector verification against the DOM, safety guards on actions. Nothing untrusted passes through.

3 · Execution layer (deterministic)

MCP server + Playwright run the validated intent. Screenshots captured as evidence. Pass/fail reported.

The hard rule

No LLM calls in layer 3 — ever. Same intent, same actions, reproducible results. That is what makes it CI-safe.
